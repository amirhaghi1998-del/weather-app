# Weather App

A simple weather application built with HTML, CSS, and vanilla JavaScript.  
Users can search for a city and view current weather conditions including temperature, humidity, wind speed, and a descriptive icon.
Live Demo:https://amirhaghi1998-del.github.io/weather-app/

## Features

- Search weather by city name
- Displays temperature, humidity, and wind speed
- Shows weather icon and description
- Loading indicator while fetching data
- Error handling for invalid city names or network issues
- Responsive design with glassmorphism UI

## Technologies Used

- HTML5
- CSS3 (Flexbox, custom spinner, glass effect)
- JavaScript (ES6+)
- [OpenWeatherMap API](https://openweathermap.org/api)
